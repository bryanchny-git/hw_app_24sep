# Plan for the HW apps

Specification
1. Basic apps with basic user interface.
2. It should run on browser 
3. Allow employee apply leave using ID and pick the type (annual, medical, unpaid)
4. There is a manager section to check the queue and choose approve or reject with comment box
5. There is employee record section showing working days, balance card showing entitlement, taken and remaining days. 
6. There is a team calendar to see overlaps leave and include email notification on submission or approval
7. With yearly forward rule


Technology 
- HTML, CSS or React or Javascript
- SQL Database
